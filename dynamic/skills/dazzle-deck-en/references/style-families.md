# Style family library (dazzle-deck)

Order of style selection: **first bound the candidate domain by scenario formality (see SKILL.md §3), then within that domain name one family by the subject's temperament**. The same topic often has several viable families — avoid habitually picking the same one; families marked ★dazzle get priority consideration in free-tier scenarios. The palettes are only example directions; **every deck must tune a precise set of hex values for its topic on the spot** — never copy them verbatim.

Universal taboos (apply to all families): warm beige/cream/rice-paper bases (#FBF7F0-style warm whites where R>G>B) are forbidden as the main background; aged-paper textures forbidden; fonts must avoid the Inter/Roboto/Arial/Open Sans/Lato/Space Grotesk default routine.

**Banned style: Swiss minimal / International Typographic Style (swiss_typographic) — never use it.** Even for formal/academic/research scenarios, switch to dark business, editorial magazine, data dashboard, or other composed families instead of the "Swiss minimal / grid typography" routine.

## Composed cluster (the mainstay for formal-tier scenarios)

### editorial_magazine — magazine editorial style
- **Temperament**: big headlines + column-width contrast, drop caps, mixed text-image layouts, whitespace rhythm — like a high-end magazine feature.
- **Applicable**: industry insights, cultural content, brand stories, annual reviews; **forbidden**: heavily data-driven monitoring reports.
- **Palette examples**: ink black #141414 + cool white #FAFAF8 (replacing off-white) + wine red #8E2433 / deep navy #10243E + gilded gold #C9A227.
- **Font direction**: display serif (rotate beyond Playfair: Libre Caslon / Zilla Slab / Noto Serif SC), body in contrasting sans-serif.
- **Fancy leverage**: mask reveal on drop caps/titles, irregular image crops + parallax, staggered entrance of column blocks, transitions with reading rhythm (horizontal shift + blur dissolve).

### data_dashboard — data journalism / dashboard
- **Temperament**: charts first, precise numbers, panel grid, calm palette + functional accents.
- **Applicable**: business reporting, earnings, operations reviews, research data; **forbidden**: lyrical cultural narratives.
- **Palette examples**: deep space blue #0D1B2A + cyan #4CC9F0 + amber warning #FFB703 / carbon black #101418 + fluorescent green #00E676 + grayscale matrix.
- **Font direction**: geometric sans display; numbers must be monospace (JetBrains Mono / IBM Plex Mono).
- **Fancy leverage**: chart entrance animations (bar growth, line draw-in, donut sweep), KPI count-up, panel border/divider light sweeps, background radial glow micro-pulses (**no square grid textures**), data-point hover glow. The family most able to "dazzle where it belongs" within the formal tier — perform the data.

### luxury_minimal — luxury minimal / high-end whitespace
- **Temperament**: generous whitespace, slender serifs, metallic/monochrome accents, slow elegant motion pacing.
- **Applicable**: premium brands, watches & jewelry, real estate, art auctions; **forbidden**: children, high-energy marketing, deep technical shares.
- **Palette examples**: obsidian black #0B0B0D + champagne gold #D4B886 / deep walnut #1C1714 + cool white #F5F5F3 (replacing ivory) + brass #B08D57.
- **Font direction**: slender serif display (beyond Cormorant: Marcellus / Italiana) + minimal sans body; pair Chinese with Noto Serif SC Light.
- **Fancy leverage**: slow sheen sweeps (gradient sweep), restrained parallax, metallic gradients, letter-spacing easing open on entrance. Mind rule 6's anti-empty-shell: whitespace ≠ emptiness; the hero must carry a complete information hierarchy.

### modern_flat_saas — modern flat / product style
- **Temperament**: clean and bright, rounded cards, clear hierarchy, contemporary product language.
- **Applicable**: product introductions, feature launches, training tutorials; **forbidden**: cultural-artistic narratives (the temperament is too "tool-like").
- **Palette examples**: cool white #F7F9FB + deep indigo #2B3A67 + coral #FF6B6B / dark mode: #0F172A + sky cyan #38BDF8 + bright orange #FB923C.
- **Font direction**: friendly geometric sans (Sora / Manrope / Figtree), avoid Inter.
- **Fancy leverage**: cards floating in with stagger, micro-interaction demos of features, breathing gradient glow background (**not a grid**), hover magnetism.

## Neutral cluster (can go plain or flashy, depending on subject)

### glass_neumorphic — glassmorphism
- **Temperament**: frosted-glass blur, translucent layering, soft highlights — light and airy.
- **Applicable**: tech products, data overviews, concept showcases; **forbidden**: government/enterprise settings needing weighty authority.
- **Palette examples**: deep violet-blue base #1A1B3A + rgba-white glass panels + neon cyan/magenta accents / cool white base + low-saturation blue-gray glass.
- **Fancy leverage**: backdrop-filter stacked depth, light blobs drifting behind the glass, cards tilting in 3D following the mouse.

### organic_handdrawn — organic / hand-drawn illustration
- **Temperament**: hand-drawn lines, irregular shapes, natural colors, warm humanism (not aged-manuscript).
- **Applicable**: education, children, public welfare, lifestyle, food; **forbidden**: finance & legal, hard tech.
- **Palette examples**: forest green #2D5A3D + warm orange #E8842C + cool white replacing cream / indigo night sky #1B2A4A + firefly yellow #F5D547.
- **Font direction**: handwritten display (Chinese: LXGW WenKai / ZCOOL family) + rounded sans body.
- **Fancy leverage**: SVG path draw-in (hand-drawn stroke feel), elements gently swaying and breathing, paper-cut parallax layers (not aged).

### brutalist_web — web brutalism
- **Temperament**: exposed structure, thick borders, oversized type, raw high-contrast tension. The base color must be cool/dark/saturated, **never warm cardboard beige**.
- **Applicable**: design events, avant-garde brands, developer topics; **forbidden**: all formal-tier scenarios.
- **Palette examples**: pure black + fluorescent green #00FF66 + pure white / Klein blue #002FA7 + black + white.
- **Fancy leverage**: giant type scrolling/bouncing in, marquees, flashing borders, deliberately "hard" transitions (instant cuts + jitter frames).

### vintage_manuscript — vintage manuscript (restricted: only when the query explicitly asks for a vintage/antique-book temperament)
- Aged paper/parchment is an overused AI trope, banned by default. Even when the query names it, express the period through palette and typography — don't smear noise textures over the face of the deck.

## ★dazzle cluster (priority consideration in free-tier scenarios)

### cyberpunk_neon — cyberpunk / neon tech ★
- **Temperament**: dark base + neon accents, scanlines, HUD, glowing outlines — future metropolis.
- **Applicable**: tech launches, gaming & esports, free-tier shares on AI/data topics; **forbidden**: defenses, government/enterprise, medical.
- **Palette examples**: pure black #0A0A0B + signal green #00FF88 + warning orange #FF6B1A / deep purple night #120B1F + magenta #FF2A6D + electric cyan #05D9E8.
- **Font direction**: monospace display (JetBrains Mono / Space Mono) + clean sans body; Chinese can pair with Smiley Sans.
- **Fancy leverage**: terminal HUD elements, glitch text, CRT scanlines, canvas particle networks, neon glow pulses, data-stream backgrounds.

### immersive_3d — immersive 3D / depth experience ★ (the strong option for spatial subjects)
- **Temperament**: real 3D scenes, depth-of-field parallax, camera movement — space as narrative.
- **Applicable (spatial subjects only)**: architecture/heritage sites & gardens, celestial bodies/astronomy/space, spatial terrain & landforms (including mountains, rainforests, and other natural landscapes); secondary: molecular/crystal structures, physical products in 3D. **Forbidden**: humanistic narratives / abstract concepts / data reports / teaching and other non-spatial subjects (3D degenerates into dazzle for its own sake; creative 2D/CSS fits better), pure text-dense reporting, formal tier.
- **Palette examples**: set by the scene; keep fog color and base color unified (scene.fog matched to --bg).
- **Fancy leverage**: **code-parameterized construction of a real 3D scene** (BoxGeometry/Cone/Plane/Torus/Sphere combined into architecture · terrain · celestial bodies, ≥10 entities + the trio of lights) + a Three.js global scene running through the show, page turns driving the camera along arcs, particle starfields, depth parallax. Full examples in fancy-cookbook "Code-built 3D scene" + "Single 3D world camera waypoint moves". Lock r128 (see SKILL.md §8). **Use it only for the spatial subjects above** (don't force it onto non-spatial subjects); **once chosen, the 3D must be real — no downgrading to 2D faking immersion**.

### maximalist_collage — maximalism / collage ★
- **Temperament**: the beauty of information overload, layered stacking, clashing colors, dense sticker-style typography.
- **Applicable**: street culture, music festivals, creative open calls; **forbidden**: all formal tier + data-dense content.
- **Palette examples**: high-saturation multicolor clash (magenta/lemon yellow/electric blue/black), grounded on black or white.
- **Fancy leverage**: multi-layer offset parallax, elements scattering in then regrouping, spinning stickers, marquee strips.

### memphis_playful — Memphis / postmodern playful ★
- **Temperament**: bright clashing colors, polka dots, zigzags, irregular geometry, playful offset.
- **Applicable**: youth education, event teasers, casual team-building shares; **forbidden**: formal tier.
- **Palette examples**: cool white base (replacing cream) + magenta #F72585 + cobalt #3A0CA3 + lemon #FFD60A.
- **Fancy leverage**: geometric elements bouncing in (spring easing), shapes rotating as pages scroll, drifting polka-dot backgrounds.

### comic_pop — comic / pop art ★
- **Temperament**: halftone dots, speech bubbles, thick outlines, pop-color storytelling.
- **Applicable**: story-driven shares, playful product intros, event recaps; **forbidden**: formal tier.
- **Palette examples**: newsprint white + pop red #ED1C24 + black outlines + halftone cyan.
- **Fancy leverage**: panel-by-panel page turns (grid advance), onomatopoeia burst entrances, halftone textures, speech bubbles popping in.

### retrofuturism_y2k — retrofuturism / Y2K ★
- **Temperament**: millennium metallics, laser gradients, star-cascade/light-speed tunnel depth, chip purple-pink-cyan.
- **Applicable**: music trends, digital-culture retrospectives, creative themes; **forbidden**: formal tier.
- **Palette examples**: deep purple #1A0B2E + laser gradient (pink #FF71CE → cyan #01CDFE → purple #B967FF) + chrome silver.
- **Fancy leverage**: chrome metallic type with gradient sweeps, laser holographic finishes (conic-gradient + blend), star cascades / light-speed tunnel depth, scanning light bands. **(No perspective grid horizons — grid textures are banned outright; express Y2K depth with light-speed tunnels/star cascades.)**

### bauhaus_geometric — Bauhaus / constructivism (editorial cluster but can lean flashy)
- **Temperament**: red-yellow-blue primaries + black, circle-square-triangle, diagonal momentum.
- **Applicable**: design education, art exhibitions, creative methodology; the formal tier may use its restrained version.
- **Palette examples**: cool white #F2F2EE (replacing off-white) + true red #D90429 + cobalt #1D3AA8 + bright yellow #FFC300 + black.
- **Fancy leverage**: constructivist entrances of geometric shapes (rotation/translation counterpoint), diagonal-driven transitions, mask interplay between shapes and type.
